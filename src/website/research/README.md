# research/

Species profiles from the Research tab (D5). One folder per species:

- `profile.json`: the profile (`prompts/profile-schema.json`) with the species as typed, provider, model, time, notes and photo credits. Committed, so the team shares profiles. Created, edited, regenerated and deleted from the Research tab.
- `images/`: reference photos from Wikimedia Commons, credited in `profile.json`. Git-ignored; Regenerate fetches them again.
