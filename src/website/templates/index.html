    Install it as an app

    Download the RepTracker certificate
    Android: trust RepTracker, then install
    1. On the phone, open RepTracker (scan the code) and tap Advanced → Proceed once.
    2. Tap Download the RepTracker certificate above.
    3. Open Settings → Security and privacy → More security settings → Install from device storage → CA certificate (names vary by phone; search Settings for “CA certificate”), tap Install anyway and pick reptracker-ca.crt.
    4. Close the browser tab and open RepTracker again: no warning this time. Tap Install RepTracker here, or ⋮ → Install app.
    iPhone: trust RepTracker, then add to the home screen
    1. Open RepTracker in Safari (scan the code) and tap Show Details → visit this website once.
    2. Tap Download the RepTracker certificate above, then Allow.
    3. Open Settings → Profile Downloaded → Install.
    4. Then Settings → General → About → Certificate Trust Settings and turn on RepTracker local authority.
    5. Open RepTracker in Safari again, tap Share → Add to Home Screen.

    Check that the fingerprint on the phone matches:

    The certificate can only vouch for RepTracker's own addresses (.local names and home-network addresses), never for other websites. Remove it any time from the phone's security settings.

    Only this computer can open RepTracker now. Start it with app.py --lan (the Pi installer does) so phones on the same network can reach it.

    This installation

    Checking…

    Update downloads the branch from GitHub, installs its packages and restarts RepTracker (about a minute). Animals, profiles, the account and the API key stay; Toy mode's sample animals go back to the branch's.

    Uninstall

    Stops RepTracker, removes it from this Pi and gives the Pi its old name back. System packages (git, Python, ffmpeg) stay.

      Upload sensor data 
      
          
      
            
            
          
      
          
      A .json file: {"t": 300000, "value": [86.8, 86.9, …]}. t is the time between samples in ms; value is the samples. The series starts when an animal is added and loops. Units are set per animal. Default files are built in and available in every mode.
