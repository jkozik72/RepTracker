# Delete cameras, edit lizards (chat messages)

## Summary

Two requests: delete camera videos that were uploaded, and edit a lizard after it is added.

## Key points

- (Message 1) Delete cameras the user added.
- (Message 2) An edit button for lizards.

## Relevance

Editing fixes a lizard set up wrongly (for example a top camera view on a side-view video) without losing its analyses.

## Open questions

None.

## Actions

- [x] Settings uploads: delete an uploaded video (confirmation; refused for sample videos and for a video a lizard still uses)
- [x] Lizard card: Edit opens the lizard form filled in; saving keeps the lizard's id, start time and analyses
