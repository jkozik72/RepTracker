# Vision always on (chat message)

## Summary

The "Use vision" option on questions is removed: every question is sent with the current camera picture.

## Key points

- (Message) Remove the option to enable vision; always on.

## Relevance

Every question to a real provider now includes an image, which costs more tokens per question than text alone.
