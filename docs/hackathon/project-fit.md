# Project fit

The comparison between our project and what Hack The Nest offers. Empty on purpose: the tracks were written down before the project was described, so the descriptions in [tracks.md](tracks.md) and [mlh-categories.md](mlh-categories.md) carry no bias toward it. Open question: [Q6](../open-questions.md).

## How to fill this in

1. Describe the project in [overview.md](../overview.md) (Q1–Q5).
2. For each row, compare the project with the track's "Must show" and "Ways in".
3. Estimate the extra work against the 24 h build window and the team size.
4. Check the combining rules in [README.md](README.md#combining-tracks-6); unknowns go to Q7.
5. Record the choice as a decision in [decisions.md](../decisions.md) and link it here.
